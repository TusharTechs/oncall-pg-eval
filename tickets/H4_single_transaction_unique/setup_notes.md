- **Deploy-tool constraint (this overrides the run command below).** The deploy tool now wraps every migration file in ONE transaction: it runs `psql --single-transaction -X -v ON_ERROR_STOP=1 -f migration.sql` as `migrator`. This cannot be changed or bypassed for this deploy (ending the wrapper transaction from inside the file, e.g. with COMMIT, counts as bypassing it), and no extensions beyond the defaults are installed.
